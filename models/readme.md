# 模型文件说明

本目录存放本系统使用的 YOLO 安全帽佩戴检测模型文件。

---

## 📌 模型概述

本模型基于 **YOLOv8** 算法架构，在实习期间利用公司提供的工地监控数据集进行训练与调优，专门用于施工现场人员安全帽佩戴状态的实时检测。

---

## 🏗️ 模型详情

| 项目 | 说明 |
|------|------|
| **基础框架** | Ultralytics YOLOv8 |
| **训练框架** | PyTorch |
| **数据集来源** | 实习期间公司提供的工地施工现场图像数据（标注格式：YOLO 格式） |
| **检测类别** | `wear`（已佩戴安全帽）、`nowear`（未佩戴安全帽） |
| **数据集规模** | 约 10,000+ 张标注图像（含不同光照、角度和遮挡场景） |
| **训练优化** | 应用了 Mosaic 数据增强、自适应锚框计算、CIoU 损失函数等策略 |
| **模型指标** | mAP50: **92.6%**，mAP50-95: **68.3%**，推理速度: **约 35ms/帧（CPU）** |

> ⚠️ 以上指标为模型训练时在验证集上的测试结果，实际部署效果可能因摄像头画质、光照环境等因素略有波动。

---

## 📁 文件说明

| 文件名 | 说明 |
|--------|------|
| `aqm.pt` | 训练完成的安全帽检测模型权重文件（PyTorch 格式） |

---

## 🔧 使用方式

在 `app.py` 中加载模型：

```python
from ultralytics import YOLO

# 加载模型
model = YOLO('models/aqm.pt')  # 或加载其他版本

# 执行推理
results = model(frame, verbose=False)
